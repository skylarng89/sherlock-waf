# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-10-28

## Context

Sherlock is built over many work sessions and, over time, by more than one person. Nobody can rely on remembering earlier reasoning, so decisions must be written down where they will be read.

## Decision

Keep ADRs in `docs/architecture/adr/`. Contributors read the relevant ADRs before changing an area and propose a new ADR rather than silently deviating.

## Consequences

Slight overhead per decision; much less re-litigation and drift.
